# Ride Dashboard Support — Deutsch

[English](support-en.md) | [Deutsch](support-de.md) | [Startseite](README-de.md) | [Issue erstellen](https://github.com/felix-lorenz/ride-dashboard-support/issues/new/choose)

Support erfolgt über GitHub Issues:
https://github.com/felix-lorenz/ride-dashboard-support/issues

Vor einem neuen Issue bitte prüfen, ob das Problem bereits gemeldet wurde. Für
eine aussagekräftige Meldung folgende Angaben ergänzen:

- Version von Ride Dashboard
- Edge-Modell und Firmwareversion
- Gerätesprache und metrische/imperiale Einstellung
- Datenfeldformat, zum Beispiel breit oder halbbreit
- ausgewählter Wert, Vorlage, Art und Position der Zusatzleiste sowie relevante
  Ride-Dashboard-Anzeigeeinstellungen
- genaue Schritte zum Reproduzieren
- erwartetes und tatsächliches Verhalten
- zugeschnittenes Bildschirmfoto oder Foto ohne private Informationen

GitHub Issues sind öffentlich. Keine FIT-Dateien, vollständigen
Aktivitätsexporte, Kontodaten, Gesundheitsdaten oder genauen Standorte
anhängen. Falls für die Diagnose eine Aufzeichnung erforderlich sein sollte,
zuerst konkrete Anweisungen abwarten und persönliche sowie Standortdaten vor
der Weitergabe entfernen.

Bei einem nicht verfügbaren Wert `-` zuerst die im Untertitel genannte Route,
das Fahrerprofil, die Sensor- oder Schaltungsverbindung beziehungsweise das
Solar-Gerätemodell prüfen.

Wechselt eine sensorabhängige Kachel zwischen einem roten Warnzustand und der
normalen Darstellung, bitte prüfen, ob der Sensor oder die elektronische
Schaltung gekoppelt, aktiv und aktuell datenliefernd ist. Die Warnung bedeutet,
dass Ride Dashboard keinen Messwert erhält; sie beweist keinen Abbruch der
Funkverbindung. Garmin kann einen alten Wert weiterreichen, der dann wie ein
gleichbleibender Live-Wert aussieht.
