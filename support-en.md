# Ride Dashboard Support — English

[English](support-en.md) | [Deutsch](support-de.md) | [Home](README.md) | [Open an issue](https://github.com/Usebit/ride-dashboard-support/issues/new/choose)

Support is provided through GitHub Issues:
https://github.com/Usebit/ride-dashboard-support/issues

Before opening a new issue, search the existing issues for the same problem.
For a useful report, include:

- Ride Dashboard version
- Edge model and firmware version
- device language and metric/imperial setting
- data-field geometry, for example full-width or half-width
- selected metric, preset, additional-strip mode and position, and relevant
  Ride Dashboard display settings
- exact steps to reproduce
- expected and actual behavior
- a cropped screenshot or photo when it does not expose private information

GitHub Issues are public. Do not attach FIT files, complete activity exports,
account information, health data, or precise locations. If a recording is ever
needed for diagnosis, wait for specific instructions and remove personal and
location data before sharing it.

For unavailable values shown as `-`, first verify the required route, rider
profile, sensor connection, electronic shifting, or Solar device model shown in
the metric subtitle.

If a sensor-dependent tile alternates with a red warning state, verify that the
sensor or electronic shifting is paired, awake, and currently supplying data.
The warning indicates missing values made available to Ride Dashboard; it does
not prove that the wireless connection itself has disconnected. Garmin may
continue to expose a stale value, which can look like a steady live reading.
