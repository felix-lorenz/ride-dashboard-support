# Ride Dashboard Privacy Policy — English

Last updated: 2026-09-25

This policy applies to the Connect IQ data field `Ride Dashboard`, App ID
`C12F8E998FE7431CA90F03F9C5B8839E`.

## Data used on the device

Ride Dashboard reads current activity values made available by Garmin, such as
speed, distance, time, navigation, sensor, electronic-shifting, battery, and
solar values. With Garmin's `UserProfile` permission, it can read profile values
needed for calculations such as W/kg, FTP percentage, and heart-rate zones.

This data is used only to calculate and draw the configured data field on the
Edge. Ride Dashboard does not keep an activity, sensor, profile, or location
history.

## Local storage

The selected metrics, maximum tile count, and display settings are stored
locally in Garmin Connect IQ application storage on the device. The in-app
reset command restores the default configuration.

## Network and sharing

Ride Dashboard has no network service, user account, advertising, analytics,
or tracking. It does not transmit activity, sensor, profile, location, or app-
settings data to the developer or any other server.

Garmin independently processes Store downloads, installation, synchronization,
and device-account data under Garmin's own terms and privacy policies. Ride
Dashboard does not receive that personal information.

The optional Ko-fi link in the Store listing opens an external website. Ride
Dashboard does not transmit data to Ko-fi or receive any visit or payment data.
Ko-fi and the selected payment provider process optional tips under their own
privacy policies.

## Contact

Privacy questions can be submitted through the public support tracker:
https://github.com/felix-lorenz/ride-dashboard-support/issues

Do not include private activity, health, account, or precise location data in a
public issue.
